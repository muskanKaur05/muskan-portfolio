# 🌸 Muskan Portfolio – Git & GitHub Practice Project

This project was created as part of my **Git & GitHub learning journey**, demonstrating complete version control workflows — from repository setup to GitHub Pages deployment.  
It also showcases my understanding of branching, merging, tagging and collaborative workflows used in **real-world DevOps environments**.

---

## 🚀 Project Overview

- Created a simple **static website** using **HTML, CSS and JavaScript**.
- Practiced **end-to-end Git operations** including initialization, branching, merging, tagging and publishing.
- Deployed the project live using **GitHub Pages**.

---

## 🧠 Key Learnings

### 🏗️ Repository Setup
- Initialized a new Git repository using `git init`.
- Added local files and committed changes with `git add` and `git commit`.

### 🌿 Branching & Collaboration
- Created feature branches (`feature/about`, `feature/contact`).
- Opened and merged Pull Requests (PRs) via GitHub.
- Resolved merge conflicts and maintained clean commit history.

### 🌍 Remote Repository Management
- Linked local repository with GitHub using:
`git remote add origin <repo-url>`
`git push -u origin main`

- Practiced `git pull`, `git fetch`, and branch synchronization with remote.


### 🏷️ Versioning & Deployment
- Tagged first release using:
`git tag v1.0.0`
`git push origin v1.0.0`

- Hosted the project through **GitHub Pages** under the main branch.

### 📊 Visualization & History
- Used:
`git log --oneline --graph --decorate --all`

to visualize commit history.
- Compared commits and tracked file changes with `git diff` and `git log --follow`.
